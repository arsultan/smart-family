# ANAI MVP

Быстрый MVP-прототип семейного AI-приложения на основе документов из `docs`.

## Что внутри

- Детский режим: главная, голосовой CTA, чат-помощник, расписание, профиль памяти.
- Родительский режим: дашборд, управление расписанием, активность, настройки доверия.
- Мок-логика ANAI: поддерживающие ответы, помощь с дробями, напоминания о расписании.
- Локальное хранение состояния через `localStorage`.
- Без внешних зависимостей, открытого интернета, платежей и сложной геймификации.

## Как открыть

Откройте `index.html` в браузере.

Если нужен локальный сервер:

```bash
node server.mjs
```

Затем перейти на `http://localhost:8000`.
